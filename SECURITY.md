# Security

This product holds law firms' client records and trust money. Security
reports are taken seriously and handled with priority.

**Report privately, never in a public issue.** Use GitHub's private
vulnerability reporting on this repository ("Report a vulnerability" under
the Security tab). You will get an acknowledgement, an honest assessment,
and credit in the release notes if you want it.

**In scope:** the application, the schema and its guards, the country packs,
and the documented deployment shape — anything that lets someone read or
move what the permission model says they cannot.

**Please do not** test against a law firm's live installation. A disposable
install is quick to stand up (see "Running it in production" and "First run"
in the README) and behaves identically.

**No bounty programme exists.** What we offer is fast honest handling,
fixes that ship with their own proofs, and public credit.
